## Project Overview
This project demonstrates my understanding of digital literacy skills required for students in today's digital world. It includes creating professional online profiles, learning safe online communication, exploring coding platforms, understanding email etiquette, and developing awareness about cybercrime prevention.

Created an infographic using Canva explaining digital literacy, online safety practices, useful digital tools, and importance of professional online presence.

## Task 2 – Student Digital Portfolio
